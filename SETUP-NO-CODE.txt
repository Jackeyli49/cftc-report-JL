NO-CODE SETUP

1. Unzip this package.
2. Create a GitHub repository.
3. Upload ALL files and folders, including .github.
4. In GitHub, open Actions > Update CFTC data > Run workflow.
5. Connect the repository to Vercel.
6. Deploy with Framework Preset: Other; Build Command: blank; Output Directory: blank.

After this, official CFTC positioning data updates automatically every Friday,
with a Saturday retry for delayed releases.

Note: price changes are not included because CFTC does not provide settlement prices.
